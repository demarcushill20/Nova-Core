## 1. Report Structure

The daily summary is a JSON file written to `OUTPUT/novatrade/daily_summary_YYYY-MM-DD.json` at the end of each trading day (or on demand).

## 3. Field Definitions

### Top-Level

| Field | Type | Description |
|-------|------|-------------|
| `date` | string | ISO date (YYYY-MM-DD) |
| `cycles_run` | int | Total monitoring cycles executed today |
| `fills_detected` | int | Pending→filled transitions detected by reconciliation |
| `broker_closes_detected` | int | Broker-side position closes detected (SL/trailing stop) |

### Health

| Field | Type | Description |
|-------|------|-------------|
| `health.ok` | int | Successful health checks |
| `health.failed` | int | Failed health checks (adapter DOWN or exception) |

### Risk

| Field | Type | Description |
|-------|------|-------------|
| `risk.halts_active` | int | Number of risk halt events active at summary time (0 or 1) |
| `risk.denials` | int | Pre-trade risk denials today |

### Actions

| Field | Type | Description |
|-------|------|-------------|
| `actions.cancel` | int | Pending orders successfully cancelled by risk action |
| `actions.flatten` | int | Positions successfully closed by risk flatten action |
| `actions.cancel_failures` | int | Cancel attempts that failed |
| `actions.flatten_failures` | int | Flatten attempts that failed |

### Reconciliation

| Field | Type | Description |
|-------|------|-------------|
| `reconciliation.mismatches` | int | State mismatches detected |
| `reconciliation.orphan_positions` | int | Broker positions with no matching agent state |
| `reconciliation.orphan_pending` | int | Broker pending orders with no matching agent state |
| `reconciliation.manual_reviews` | int | Issues requiring operator manual review |

### Alerts

| Field | Type | Description |
|-------|------|-------------|
| `alerts.critical` | int | CRITICAL alerts emitted today |
| `alerts.warning` | int | WARNING alerts emitted today |
| `alerts.info` | int | INFO alerts emitted today |

### Current State

| Field | Type | Description |
|-------|------|-------------|
| `state.agent_state` | string | Current Trading Agent FSM state |
| `state.halt_status` | bool | Whether risk engine is halted |
| `state.halt_reason` | string | Reason for halt (empty if not halted) |
| `state.equity` | float | Current tracked equity |
| `state.pnl_today_usd` | float | P&L for today in USD |

---

## 4. Generation

The daily summary is generated by calling:

```python
monitor = OpsMonitor(cfg, adapter, agent, risk_engine, recorder)
# ... run monitoring cycles throughout the day ...
summary = monitor.generate_daily_summary()
path = monitor.write_daily_summary(summary, "OUTPUT/novatrade")
```

Call `monitor.reset_daily_tracking()` at the start of each new trading day to reset counters.

---

## 5. Retention

Daily summary files are retained indefinitely for audit purposes. They are small (~1KB each) and provide the primary operational record for each trading day.
